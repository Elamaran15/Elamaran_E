[03] Featured build

featured · personal project · 2025

Bankly

A cloud-native microservices banking platform, built end to end.

An event-driven User, Transaction and Payment trio. Transfers validate synchronously (WebClient) and settle asynchronously (Kafka), behind Spring Cloud Gateway, Eureka, Config and Resilience4j. It runs on GKE behind an Ingress, ships through GitHub Actions with keyless Workload Identity Federation, and is traced end to end with Zipkin.

  • 25K+impressions on launch
  • 10/10GKE workloads OK
